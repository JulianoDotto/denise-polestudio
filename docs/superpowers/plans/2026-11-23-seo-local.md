# SEO local: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fazer o Google entender o site como um estúdio de pole dance em Caçapava/SP que atende a
região, e fazer a home e `/aulas` falarem o que a aluna nova busca.

**Architecture:** A lógica pura fica em `lib/seo.ts`, com TDD: URL base, entradas do sitemap,
regras do robots e JSON-LD do estúdio. As rotas de metadados do Next (`app/sitemap.ts`,
`app/robots.ts`) e o layout só chamam essas funções. Os textos novos entram em
`hardcoded/texts.ts`.

**Tech Stack:** Next.js 16 App Router (Metadata API, `MetadataRoute`), TypeScript, `tsx --test`
com `node:test` e `node:assert/strict`.

**Spec:** `docs/superpowers/specs/2026-11-23-seo-local-design.md`

## Global Constraints

- URL base: `NEXT_PUBLIC_SITE_URL`. Padrão: `https://denisegarcia.vercel.app`, sem barra no fim.
- Páginas públicas no sitemap: `/`, `/aulas`, `/workshops`, `/eventos`, `/produtos-digitais`, `/loja`.
- O robots bloqueia `/login`, `/logout`, `/403` e `/api/`. `/login`, `/logout` e `/403` têm `robots: { index: false, follow: false }`.
- JSON-LD: `@type` `SportsActivityLocation`. `areaServed`: Caçapava, São José dos Campos, Taubaté. Sem `openingHoursSpecification`.
- Endereço, telefone e Instagram vêm das chaves `SITE_FOOTER_*` de `hardcoded/texts.ts`, sem copiar os valores.
- Só fatos que já estão no site. Nada de preço, horário, aula experimental ou idade.
- Sem mudança visual: `PageHero` e o layout das páginas ficam iguais.
- Trabalhar em worktree e não trocar de branch na pasta principal. Não parar o `localhost:3000`.
- Toda mudança de página atualiza `docs/superpowers/specs/site/` no mesmo commit.
- Depois do push na `main`, não conferir o deploy.

## Review Focus

- `NEXT_PUBLIC_SITE_URL` com barra no fim (`https://x.com.br/`): sem `//` nas URLs geradas. Teste na Task 1.
- `NEXT_PUBLIC_SITE_URL` vazia, só espaços ou sem `http(s)://`: cai no padrão. Teste na Task 1.
- Texto com `</script>` no JSON-LD não fecha a tag. Teste de `serializeJsonLd` na Task 1.
- O título da home não sai com "Denise Garcia" duas vezes. Conferência na Task 3.
- `NEXT_PUBLIC_*` entra no build. Trocar o domínio exige um novo deploy. Isso vai para a documentação na Task 2.

- [ ] **Step 1: Escrever os testes que falham em `lib/seo.test.ts`**

```ts
import assert from 'node:assert/strict'
import test from 'node:test'
import { TEXTS } from '../hardcoded/texts'
import { DEFAULT_SITE_URL, PUBLIC_PATHS, buildRobots, buildSitemapEntries, buildStudioJsonLd, getSiteUrl, serializeJsonLd } from './seo'

test('site url falls back to the default when missing or invalid', () => {
  for (const raw of [undefined, '', '   ', 'denisegarcia.com.br', 'ftp://x.com']) {
    assert.equal(getSiteUrl(raw), DEFAULT_SITE_URL)
  }
})

test('site url keeps a valid value and drops trailing slashes', () => {
  assert.equal(getSiteUrl('https://denisegarcia.com.br/'), 'https://denisegarcia.com.br')
  assert.equal(getSiteUrl('  https://denisegarcia.com.br  '), 'https://denisegarcia.com.br')
})

test('sitemap lists the six public pages under the site url', () => {
  const urls = buildSitemapEntries('https://x.com.br').map((entry) => entry.url)
  assert.deepEqual(urls, ['https://x.com.br', 'https://x.com.br/aulas', 'https://x.com.br/workshops', 'https://x.com.br/eventos', 'https://x.com.br/produtos-digitais', 'https://x.com.br/loja'])
  assert.equal(PUBLIC_PATHS.length, 6)
})

test('robots allows the site, blocks internal pages and points to the sitemap', () => {
  const robots = buildRobots('https://x.com.br')
  const rule = Array.isArray(robots.rules) ? robots.rules[0] : robots.rules
  assert.equal(rule.userAgent, '*')
  assert.equal(rule.allow, '/')
  assert.deepEqual(rule.disallow, ['/login', '/logout', '/403', '/api/'])
  assert.equal(robots.sitemap, 'https://x.com.br/sitemap.xml')
})

test('studio json-ld describes the local studio from the site texts', () => {
  const data = buildStudioJsonLd('https://x.com.br') as any
  assert.equal(data['@context'], 'https://schema.org')
  assert.equal(data['@type'], 'SportsActivityLocation')
  assert.equal(data.name, TEXTS.SITE_STUDIO_NAME_1)
  assert.equal(data.url, 'https://x.com.br')
  assert.equal(data.image, 'https://x.com.br/opengraph-image.jpg')
  assert.equal(data.telephone, '+5512988153159')
  assert.deepEqual(data.sameAs, [TEXTS.SITE_FOOTER_INSTAGRAM_URL_1])
  assert.deepEqual(data.address, { '@type': 'PostalAddress', streetAddress: TEXTS.SITE_FOOTER_ADDRESS_LINE_1, addressLocality: 'Caçapava', addressRegion: 'SP', addressCountry: 'BR' })
  assert.deepEqual(data.areaServed.map((c: any) => [c['@type'], c.name]), [['City', 'Caçapava'], ['City', 'São José dos Campos'], ['City', 'Taubaté']])
  assert.equal('openingHoursSpecification' in data, false)
})

test('json-ld serialization cannot close the script tag', () => {
  const out = serializeJsonLd({ name: '</script><script>alert(1)</script>' })
  assert.equal(out.includes('<'), false)
  assert.deepEqual(JSON.parse(out), { name: '</script><script>alert(1)</script>' })
})
```
